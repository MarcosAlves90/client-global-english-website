# Repository POLIS records

Keep durable POLIS inputs and outputs in this directory:

- `policy.json`: project validation policy.
- `contracts/`: draft and POLIS-locked Change Contracts.
- `plans/`: contract-bound implementation plans and policy compilation reports.
- `artifacts/<change>/`: regression proofs and delivery packages.

The POLIS 6.8.1 producer needs its working inputs and outputs outside the target worktree. Follow [the repository POLIS workflow](../docs/POLIS.md), then archive validated outputs here byte-for-byte.
